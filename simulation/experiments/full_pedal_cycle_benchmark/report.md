# Ресурсы полного шага педали на STM32G474

Подготовлена отдельная измерительная прошивка для двух каскадных решателей:

- дешёвый: `Q4+Q3 3×3 → Q2 1×1 → Q1 2×2 → Q1 2×2`;
- надёжный: `Q4+Q3+Q2 4×4 → Q1 2×2 → Q1 2×2`.

Оба варианта используют одни и те же коэффициенты полной приведённой модели при
`Sustain = 1`, `Tone = 1`, `Volume = 0,8`, частоте 384 кГц и 13 переменных состояния.
За один шаг выполняются линейное предсказание, 14 обращений к CORDIC, каскадные
поправки, расчёт выхода и обновление всех состояний.

## Уже измеренные ресурсы сборки

| Величина | Значение |
|---|---:|
| Код и постоянные данные во флеше | 17 604 байта |
| Из них таблица проверочного потока | 3 072 байта |
| Статические данные в ОЗУ | 40 байт |
| Наибольшая рамка функции обработки потока | 376 байт |
| Оценка наибольшей цепочки вызовов измерителя | около 628 байт стека |

Размер 17 604 байта включает запуск контроллера, измеритель, печать результатов,
оба решателя и проверочный поток. Это не размер будущего звукового ядра. Коэффициенты
модели и входной поток лежат во флеше, поэтому счётчик статической памяти не отражает
рабочий стек.

## Такты на STM32G474 при 170 МГц

| Часть | Такты |
|---|---:|
| Шесть нелинейностей через CORDIC | 702 |
| Решатель 2×2 | 35 |
| Решатель 3×3 | 40 |
| Решатель 4×4 с выбором главного элемента | 673 |
| Линейное предсказание шести переменных | 1 070 |
| Выход и обновление 13 состояний | 2 631 |
| Полный дешёвый шаг, среднее | 6 320 |
| Полный надёжный шаг, среднее | 6 867 |
| Наибольший полный дешёвый шаг | 6 321 |
| Наибольший полный надёжный шаг | 6 868 |

Бюджет при 170 МГц и 384 кГц равен 442,7 такта. Дешёвый вариант превышает его в
14,28 раза, надёжный — в 15,51 раза. Это соответствует 1 428 % и 1 551 % одного ядра.
Оба прогона завершились без нечисловых значений. Конечные выходы C отличаются от расчёта Python
на 0,167 мВ и 0,161 мВ соответственно; значит измерена рабочая, а не развалившаяся
траектория.

Если грубо считать стоимость шага неизменной при смене частоты, загрузка ядра будет
такой:

| Повышение частоты | Дешёвый | Надёжный |
|---:|---:|---:|
| 1×, 48 кГц | 178 % | 194 % |
| 2×, 96 кГц | 357 % | 388 % |
| 4×, 192 кГц | 714 % | 776 % |
| 8×, 384 кГц | 1 428 % | 1 551 % |

Таким образом, текущая реализация не помещается даже на 48 кГц. Выбирать повышение
частоты до сокращения арифметики преждевременно; практической целью после первой
оптимизации разумно считать 2× или 4×, а не сразу 8×.

Главный потребитель сейчас — линейная часть: предсказание и обновление состояния
суммарно стоят 3 701 такт. Шесть начальных нелинейностей стоят 702 такта, а полный
шаг вызывает CORDIC 14 раз. Решатель 3×3 уже дешёв, но универсальный решатель 4×4
стоит 673 такта и объясняет почти всю разницу между кандидатами.

Следующая оптимизация должна разделяться на три независимые задачи:

1. Перенести плотные линейные произведения на FMAC или сократить их структуру.
2. Заменить повторные обращения к CORDIC обновлением нелинейностей по малому
   приращению, оставив периодическое точное восстановление.
3. Развернуть конкретный решатель 4×4 без общего исключения Гаусса и выбора строк.

Из-за отказа отладочного канала ST-Link прошивка была успешно записана через штатный
накопитель `NOD_G474RE`. Для этой цели выбран способ записи `mbed`:

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\platformio.exe" run -e full_pedal_benchmark -t upload
```

## Сокращение линейной арифметики

Плотная матрица перехода 13×13 заменена диагональным представлением в собственных режимах линейной системы. Это точная замена координат: физическая модель и шесть активных нелинейностей не меняются. После округления коэффициентов до `float32` пиковая разность с исходными координатами на проверочном потоке равна 0,361 мВ.

Дополнительно коэффициенты перенесены во внутреннее ОЗУ, разрешено объединение умножения со сложением, предсказатель и проекция 6×6 считают несколько строк параллельно. Итоговый замер на той же плате:

| Часть | Первая версия, тактов | Текущая версия, тактов |
|---|---:|---:|
| Шесть нелинейностей | 702 | 722 |
| Решатель 2×2 | 35 | 31 |
| Решатель 3×3 | 40 | 26 |
| Решатель 4×4 | 673 | 648 |
| Линейное предсказание | 1070 | 533 |
| Выход и обновление состояния | 2631 | 1154 |
| Полный дешёвый шаг | 6320 | **4496** |
| Полный надёжный шаг | 6867 | **5037** |

Линейная часть сократилась с 3701 до 1687 тактов, то есть в **2,19 раза**. Полный дешёвый шаг стал дешевле на 1824 такта, или на **28,9%**. Итог дешёвого прогона отличается от расчёта Python примерно на 0,161 мВ; нечисловых значений нет. При 384 кГц шаг всё ещё превышает бюджет 442 такта в 10,17 раза, поэтому одной перестройки линейной арифметики недостаточно.

Текущая измерительная сборка занимает 15 756 байт флеша и 1096 байт статического ОЗУ. В эту величину по-прежнему входят проверочный поток, печать результатов и служебная часть измерителя.

## Сохранённые нелинейности

После линейной оптимизации все четыре экспоненциальные и две диодные функции переведены на сохранённое состояние. Малое приведённое приращение вычисляется кубическим многочленом; при модуле выше 0,25 выполняется точный пересчёт CORDIC. Полное периодическое восстановление выполняется раз в 64 шага.

Шесть обычных обращений к сохранённому состоянию занимают 179 тактов, точное восстановление всех шести — 763 такта. Полный дешёвый поток сократился с 4496 до **3539 тактов** в среднем, максимум равен 4362. От первой версии 6320 → 3539 тактов, то есть полная экономия достигла **44,0%** без удаления физики.
