# Такты каскадного frontend на STM32G474

Первая специализированная C-реализация содержит два локальных блока:
`Q4+Sustain+Q3+C13` с поправкой 3×3 и `R12+Q2` со скалярной диодной поправкой.
Связь через R12 использует линейный предиктор напряжения базы Q2.

| Величина | Значение |
|---|---:|
| Ядро | 170 МГц |
| Бюджет 48 кГц | 3541 такт |
| Четыре frontend-шага, среднее | **11949 тактов** |
| Четыре frontend-шага, максимум | **11960 тактов** |
| NaN/Inf | 0 |
| Flash измерительной сборки | 8272 байта |

Это baseline без кэша нелинейностей. Каждый малый шаг повторно вычисляет токи и
производные до и после Newton-поправки, поэтому цена определяется восемью обращениями к CORDIC
на внутренний шаг. Следующая версия должна использовать сохранённые `sinh/cosh` и локальное
обновление по малому приращению.

## Incremental-кэш

После добавления сохранённых `sinh/cosh`, кубического обновления при \(|\Delta q/s|\leq0{,}25\)
и полного восстановления раз в 64 внутренних шага получено:

| Величина | Без кэша | С кэшем |
|---|---:|---:|
| Среднее, тактов/48 кГц | 11949 | **9278** |
| Максимум | 11960 | **10478** |
| Возвраты к CORDIC после большого шага | — | 720 за 8 прогонов |
| NaN/Inf | 0 | 0 |

Средняя цена сократилась на 22,4%, но frontend 4× всё ещё занимает 262% всего бюджета.
Следующие рычаги — разворачивание и разреживание аффинных карт, а также отдельный замер 2×.

## Честный режим 1×

Для 1× проводимости всех конденсаторов пересчитаны для \(h=1/48000\) с, а на один входной
отсчёт выполняется ровно один проход `Q4+Q3 → Q2`.

| Величина | Значение |
|---|---:|
| Частота | 48000 Гц |
| Бюджет | 3541 такт |
| Frontend 1×, среднее | **2370 тактов** |
| Frontend 1×, максимум | **3070 тактов** |
| Средний запас frontend | 1171 такт |
| Минимальный запас frontend | 471 такт |
| NaN/Inf | 0 |
| Возвраты к CORDIC | 736 за 8 прогонов |

На 250-мс численном опыте Sustain=1, Tone=1 и 200 мВ модель 1× устойчива. Ошибка на коллекторе
Q2 относительно общей модели 4× равна 26,77 мВ СКО и 429,6 мВ в пике. Пиковая ошибка сосредоточена
на атаках; поэтому 1× является realtime-baseline, но не окончательным критерием качества.

### Разреживание и гибридный incremental-кэш

Генератор зануляет аффинные коэффициенты меньше \(10^{-7}\). GCC удаляет соответствующие
умножения. Перенос коэффициентов из Flash в SRAM не изменил цену ни одной фазы и был отклонён.

Обновление `sinh/cosh` выбирает кубический ряд при \(|d|\leq0{,}25\), пятый поряд при
\(0{,}25<|d|\leq0{,}5\) и CORDIC за пределами этого диапазона.

| Вариант | Среднее | Максимум | Fallback |
|---|---:|---:|---:|
| Исходный 1× | 2370 | 3070 | 736 |
| Разрежение, кубический до 0,25 | 2238 | 2966 | 736 |
| Пятый поряд до 0,5 | 2281 | 2843 | 376 |
| Гибридный | **2246** | **2844** | **376** |

Относительно первой 1×-версии средняя цена сократилась на 124 такта, а максимум — на 226 тактов.

## Полный тракт 1×

Коэффициенты Tone–Q1–Volume пересчитаны для 48 кГц и включены в тот же измеряемый шаг.
Q1 сохраняет две Newton-поправки: одна поправка на длинном тяжёлом опыте неустойчива.

После двух поправок удалена избыточная пост-проекция Q1 и повторное обновление двух кэшей. Это сократило
полный шаг с 3464/4411 до 3275/4209 тактов. После разнесения шести периодических CORDIC-refresh по отдельным
отсчётам и удаления профилировочных меток чистая цена равна:

| Величина | Значение |
|---|---:|
| Полный шаг, среднее | **3256 тактов** |
| Полный шаг, максимум | **3777 тактов** |
| Бюджет | 3541 такт |
| Средний запас | 285 тактов, 8,0% |
| Превышение максимума | 236 тактов |
| NaN/Inf | 0 |

Полный тракт уже укладывается в realtime по средней цене. Следующая цель — убрать 236 тактов из редкого
максимума и освободить запас для ADC/DAC и буферизации.

### Запас и устранение пиков

Аудит худшего отсчёта показал совпадение двух CORDIC-fallback с плановым refresh. Плановое
восстановление теперь пропускается, если на том же отсчёте уже был fallback. Это уменьшило чистый
максимум с 3777 до 3565 тактов.

Для специализированной среды включён `-ffast-math`. Он разрешил GCC переассоциировать длинные аффинные
суммы и Newton-выражения. На проверочном потоке финальный выход изменился на 14,65 мкВ; NaN/Inf нет.

| Величина | До | После |
|---|---:|---:|
| Среднее, тактов | 3254 | **2806** |
| Максимум, тактов | 3565 | **3009** |
| Запас по среднему | 287 (8,1%) | **735 (20,8%)** |
| Запас по максимуму | -24 (-0,7%) | **532 (15,0%)** |

Итоговая сборка `COMPOSED_FULL_1X_OPTIMIZED_V1` укладывается в дедлайн каждым измеренным отсчётом.

## Поправка: полный сигнал и адаптивный Q2

Вывод предыдущего раздела относится только к короткому синтетическому потоку и больше не является достаточным
критерием realtime. Полный аккорд обнаружил отрицательный NaN на 325-м сэмпле; старая проверка NaN пропускала
отрицательный знак. После исправления проверки и замены Q2 на монотонный bracketed Newton расчёт устойчив.

| Вариант | Среднее блока 32 | Максимум | Опоздания | Адаптивных веток |
|---|---:|---:|---:|---:|
| Bracketed Q2 | 106561 | 148503 | 2281 / 6000 | 112030 |
| Bracketed Q2 + implicit predictor | **105035** | **136197** | **1827 / 6000** | **≈67579** |

Бюджет блока 32 равен 113312 тактам. Predictor улучшил все временные показатели и не изменил пик выхода
заметно, но realtime пока не достигнут. Актуальный критерий — ноль опозданий на всех 6000 блоках полного аккорда.
