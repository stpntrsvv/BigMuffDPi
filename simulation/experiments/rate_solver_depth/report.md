# Глубина решения при частоте 2×

Проверены две, три и четыре полные поправки быстрого блока на каждом шаге 2×.
Эталон — две поправки при 4×. Пик более 1 В считается практической потерей устойчивости.

| Режим | Худшее СКО, мВ | Худший пик, мВ | Устойчиво всюду |
|---|---:|---:|---|
| full_repeat | 612976633797119204497817600.000 | 1133122377945829798817300480.000 | нет |
| damped_half | 11.491 | 158.430 | да |
| full_triple | 653952187986778894557511680.000 | 6766454984439170329972047872.000 | нет |
| damped_quarter | 10.651 | 167.349 | да |
| full_quad | 10.483 | 169.332 | да |

Две недемпфированные поправки 2× срываются при Sustain = Tone = 1 и входах
100–200 мВ. Последовательность коэффициентов поправки `[0,5; 1,0]` сохраняет
устойчивость во всех проверенных случаях, включая 200 мВ: 11,491 мВ СКО и
158,430 мВ пика. Она требует только двух решений 4×4 на шаг, тогда как простой
устойчивый вариант требует четыре.
