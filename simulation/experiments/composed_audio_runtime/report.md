# Реальный ADC/DMA/DSP/DAC runtime

## Конфигурация

- STM32G474RE, 170 МГц;
- TIM6, 48 кГц;
- ADC1 + DMA1 Channel 1, кольцевой буфер 64 отсчёта;
- обработка полубуферами по 32 отсчёта;
- DAC1 Channel 1 + DMA1 Channel 2;
- составное физическое ядро Sustain=1, Tone=1, Volume=0,8.

Поскольку на голой плате PA1 ещё не имеет внешнего смещения к середине
питания, bring-up собран с `COMPOSED_RUNTIME_ZERO_INPUT`: ADC и оба DMA
работают физически, но в DSP передаётся цифровой ноль. Реальные ADC-коды при
этом измеряются отдельно.

|---|---:|
| Бюджет | 113312 тактов |
| Среднее callback | 91261 такт |
| Максимум callback | 91298 тактов |
| Запас худшего callback | 22014 тактов, 19,43% |
| Deadline overruns | 0 |
| DMA late flags / transfer errors | 0 / 0 |
| DAC clip / nonfinite | 0 / 0 |
| DSP fault / hold | 0 / 0 |
| ADC min / max / average | 127 / 2048 / 1215 |

ADC не находится около кода 2048, поэтому режим реального входа включать до
внешнего bias нельзя. Следующая проверка после обвязки: убрать
`COMPOSED_RUNTIME_ZERO_INPUT`, убедиться в среднем коде около 2048 без сигнала
и повторить отчёт сначала с тишиной, затем с гитарным уровнем.
