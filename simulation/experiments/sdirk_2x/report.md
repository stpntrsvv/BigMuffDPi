# SDIRK2 при 2×

Проверен L-устойчивый двухступенчатый SDIRK с совместным неявным решением
девяти состояний и четырёх нелинейных портов. Коэффициент диагонали
`γ = 1 - 1/√2`. На каждом этапе выполнялись 2–4 демпфированные поправки.
Эталон — `full_repeat` 4×/2×, сигнал — полный файл атаки 250 мс.

## Вывод

Путь закрыт. Увеличение числа поправок почти не уменьшает среднеквадратическую
ошибку тяжёлого случая, следовательно, причина не в недосходимости локального
Ньютона. При крупном шаге нынешнее портовое разбиение неверно передаёт связанную
динамику Q4–Q3–Q2 и нагрузку Tone. Дальнейшая настройка интегратора не даст
необходимого выигрыша. Следующий этап — смена архитектуры и явное сокращение
физики с новым эталонным сравнением.
