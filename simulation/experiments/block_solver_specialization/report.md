# Специализированные блочные решатели полной педали

Универсальная сборка локальной матрицы заменена прямыми ядрами для постоянных блоков `3×3`, `1×1`, `2×2` и `4×4`. Все замеры выполнены на STM32G474RE при 170 МГц, сохранённых нелинейностях и периоде точного восстановления 64.

| Маршрут | До специализации, тактов | Отдельное ядро, тактов | Экономия |
|---|---:|---:|---:|
| Дешёвый `3×3 → 1×1 → 2×2 → 2×2` | 3539 | 3532 | 7 |
| Надёжный `4×4 → 2×2 → 2×2` | 4176 | 3615 | 561 |

Для дешёвого маршрута наблюдался лучший результат 3469 тактов в одной из общих компоновок, но отдельная воспроизводимая сборка принята за основной результат. Выход специализированного ядра совпадает с предыдущим побитно.

## Проверка фиксированного 4×4

| Вход | Минимальный модуль опоры | Максимальная обусловленность | Разность с эталонным решением |
|---:|---:|---:|---:|
| ×1 | 1,000435 | 108,640 | \(3{,}47\cdot10^{-18}\) |
| ×5 | 1,000435 | 108,640 | \(6{,}94\cdot10^{-18}\) |

На проверенной области фиксированное исключение имеет большой запас по опорным элементам. Проверка воспроизводится командой:

```powershell
..\.venv\Scripts\python.exe simulation\verify_fixed_4x4.py
```

## Вывод

Главный выигрыш специализации относится к надёжному маршруту: общий решатель с выбором строк больше не является его главным недостатком. Разница с дешёвым маршрутом уменьшилась до 83 тактов, поэтому дальнейший выбор надо делать по ошибке относительно полной сходимости и длинным переходным процессам.
