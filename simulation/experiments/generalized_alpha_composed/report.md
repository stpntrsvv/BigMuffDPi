# Обобщённый α-метод в составном C-ядре

Для найденного в полной узловой модели значения `rho=0.2` сгенерированы
редуцированные коэффициенты и собран отдельный вариант составного C-ядра.
Рабочая прошивка BDF2 не изменялась.

Метод хранит масштабированную производную каждого состояния. Коэффициенты для
`rho=0.2`: `alpha_m=7/6`, `alpha_f=gamma=5/6`, эквивалентный множитель
проводимости конденсаторов — `42/25=1.68`.

Оба четырёхсекундных аккорда обработаны без срывов и удержаний.

| Вход | Вариант | Ошибка формы | Ошибка спектра |
|---:|:---|---:|---:|
| 25 мВ | составной BDF2 | 5,44% | −30,05 дБ |
| 25 мВ | составной `rho=0.2` | 5,81% | −31,95 дБ |
| 100 мВ | составной BDF2 | 7,89% | −25,29 дБ |
| 100 мВ | составной `rho=0.2` | 10,02% | −21,39 дБ |

Контроль — полная узловая модель с Эйлером 16×. Перед сравнением убраны
постоянная составляющая, целочисленная задержка и общий коэффициент усиления.

На слабом аккорде новый вариант немного лучше по спектру, но на сильном заметно
хуже BDF2. Улучшение полной узловой модели не переносится напрямую через текущую
одностороннюю связь составных блоков: α-методу требуется согласованная
промежуточная точка на их границе. Поэтому этот вариант не переносится на плату.

Файлы для прослушивания независимо приведены к одинаковому пику внутри каждого
файла и пригодны для сравнения окраски, но не абсолютного усиления:
