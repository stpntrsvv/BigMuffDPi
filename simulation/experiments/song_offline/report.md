# Офлайн-прослушивание полной гитарной партии

Эксперимент принимает пользовательскую чистую гитарную дорожку и пропускает её
через составное C-ядро Big Muff при 48 кГц и BDF2 1×. По умолчанию все три ручки
находятся в центре: Sustain=0,5, Tone=0,5, Volume=0,5.

В офлайн-сборке два кэша переходов Q1 точно восстанавливаются каждые 16 отсчётов.
Это устраняет диагностированное накопительное переполнение на длинных дорожках.
Режим пока не является рабочей прошивкой и не имеет аппаратного замера тактов.

Скрипт генерирует отдельные коэффициенты модели в каталоге результата и не меняет
рабочие заголовки прошивки. Создаются три файла:

- `dry_48k_mono.wav` — подготовленный сухой вход;
- `muff_center_legacy.wav` — вариант Q2 действующей прошивки;
- `muff_center_matched.wav` — исправленный полином Q2 для BDF2.

На вход принимается mono/stereo PCM16 или PCM24 WAV. Сигнал приводится к mono
PCM16 48 кГц. Если исходная частота отличается, применяется
простая линейная передискретизация; для окончательного прослушивания лучше заранее
экспортировать дорожку из звукового редактора в 48 кГц PCM16.

## Запуск

Из корня проекта:

```powershell
& .\.venv\Scripts\python.exe simulation\run_song_offline.py "C:\путь\clean-guitar.wav"
```

По умолчанию 99,9-й процентиль модуля сухой дорожки считается равным 100 мВ на
входе педали. Единичные пики при этом сохраняются и могут соответствовать большему
напряжению; точное значение максимума записывается в отчёт. Рабочий уровень можно
изменить, например:

```powershell
& .\.venv\Scripts\python.exe simulation\run_song_offline.py "C:\путь\clean-guitar.wav" --input-peak-mv 50
```

Для прежней нормировки строго по максимальному пику используется:

```powershell
& .\.venv\Scripts\python.exe simulation\run_song_offline.py "C:\путь\clean-guitar.wav" --input-peak-mv 50 --level-percentile 100
```

Результаты сохраняются в `simulation/experiments/song_offline/output/` вместе с
отчётом о срывах и числе адаптивных ветвей. Выходы нормируются отдельно только для
прослушивания, поэтому их относительную громкость по этим WAV сравнивать нельзя.

Для песни `Today` нужен именно сухой одиночный гитарный сигнал. Готовый микс,
гитарная дорожка уже с усилителем или выделенный алгоритмом stem одновременно
проверяют артефакты источника и не дают чистой оценки модели педали.
