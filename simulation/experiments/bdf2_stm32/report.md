# BDF2 в составном ядре STM32G474

Для составного ядра сгенерирован отдельный набор коэффициентов BDF2. Каждый
динамический блок хранит два прошлых вектора напряжений конденсаторов; перед
аффинным шагом формируется история

\[
h_n = \frac{4v_{n-1}-v_{n-2}}{3}.
\]

Проводимость конденсатора в коэффициентах равна \(3C/(2\Delta t)\). Нелинейные
законы и размер решаемых систем не изменены.
