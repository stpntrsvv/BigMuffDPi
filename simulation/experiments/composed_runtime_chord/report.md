# Полный аккорд через составное STM32-ядро

Четырёхсекундный сухой ми-мажорный аккорд 48 кГц масштабируется до 100 мВ peak и проходит через тот же C-код,
который собирается для STM32. Настройки фиксированы: Sustain=1, Tone=1, Volume=0,8.

## История устойчивости

| Вариант | Результат |
|---|---|
| Исходный optimized V1 | отрицательный NaN на сэмпле 325 |
| Ограничение Newton-step Q2 | устойчиво, но пик около 3,14 В и слышимый slew |
| Bracketed Newton Q2 | 192000 сэмплов, NaN=0, hold=0, пик 1,528 В |
| Bracketed Q2 + implicit predictor | тот же пик с разностью около 14 мкВ, меньше точных fallback |

Эталон ngspice при тех же настройках имеет пик около 1,542 В.

## Аналитический Q2 predictor

Проверен вариант без LUT: обратная нечётная функция
`y + beta*sinh(y) = t` аппроксимирована пятью полиномами пятой степени на
диапазоне полного аккорда `linear_q=[-2,443; 2,629] В`. После predictor ток
восстанавливается из KCL, а производная — через
`cosh(y)=sqrt(1+sinh(y)^2)`. Поэтому штатный путь Q2 не вызывает CORDIC;
bracketed solver сохранён только за пределами измеренного диапазона.

Host, 192000 отсчётов:

- peak `1,52800584 В`;
- DC `-0,000602235 В`;
- NaN `0`, holds `0`;
- отличие пика от bracketed+predictor около `92 мкВ`.

STM32G474RE, block=32:

| Величина | Аналитический Q2 |
|---|---:|
| Среднее | 102746 тактов |
| Максимум | 124703 такта |
| Deadline overrun | 1122 / 6000 |
| NaN / hold | 0 / 0 |

Q2 больше не входит в bracketed fallback на этом сигнале. Оставшиеся пики и
около 61504 adaptive-событий относятся к медленному 2x2 каскаду; следующую
оптимизацию следует профилировать там.

WAV: [аналитический Q2](stm32_composed_analytic_sustain100_tone100.wav).

## Realtime закрыт на block=32

Профилирование показало, что все 61504 входа slow 2x2 в damping принимали
полный шаг `lambda=1` с первой попытки. Line search удалён: для большого шага
используется текущий Jacobian, а нелинейный cache точно пересчитывается только
в принятой новой точке. Сам Newton-шаг и физические уравнения не менялись.

Из периодической refresh-карусели также исключён Q2: его аналитический путь
каждый отсчёт сам задаёт ток и производную, поэтому наследуемый cache ему не
нужен.
