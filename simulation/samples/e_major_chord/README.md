# Сухой ми-мажорный аккорд

Тестовый аккорд собран из шести сухих нот Stratocaster: `E2–B2–E3–G♯3–B3–E4`.
Источник — [cluesurf/wavebase](https://github.com/cluesurf/wavebase), файлы объявлены
общественным достоянием. Автор набора описывает их как записи настоящих
электрогитар без эффектов.

Файлы:

- `source/*.wav` — неизменённые исходные записи, стерео PCM32, 44,1 кГц;
- `e_major_dry.wav` — аккорд длительностью 4 с, моно PCM16, 48 кГц;
- `e_major_attack.wav` — первые 250 мс для быстрых численных опытов.

При сборке струны вступают снизу вверх с шагом 7 мс. Сигнал сведён в моно,
линейно пересчитан на 48 кГц и нормирован к -3 дБ от полной шкалы. Сценарий
`simulation/build_guitar_chord_sample.py` воспроизводит сборку. Физическая амплитуда в вольтах
назначается в сценариях опытов, а не зашита в WAV.
