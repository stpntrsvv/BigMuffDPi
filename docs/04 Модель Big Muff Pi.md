# Модель Big Muff Pi

## Исходная схема

В сохранённом разборе Big Muff Pi V3 выделены четыре функциональные части:

1. входной усилительный каскад;
2. два последовательных каскада усиления с симметричным диодным ограничением;
3. пассивный темброблок, смешивающий низкочастотную и высокочастотную ветви;
4. выходной усилительный каскад, возмещающий потери темброблока.

Перед расчётом цифровой модели необходимо извлечь для каждого каскада:

- передаточную характеристику малого сигнала;
- частотную характеристику;
- рабочую точку и доступный размах;
- нелинейную характеристику ограничения;
- зависимость от положений трёх регуляторов.

Подробный разбор уравнений, переменных состояния и способов дискретизации
вынесен в главу [«Математическая модель»](08%20Математическая%20модель.md).

## Реализация в программе

В `composed_audio_runtime` функция `audio_engine_process()` вызывает общее
ядро всей педали: `Q4+Sustain+Q3 → Q2 → Tone+Q1`, BDF2 1×, 48 кГц.
Сквозное копирование осталось в сборках без `COMPOSED_PEDAL_RUNTIME`.
Коэффициенты фиксированы для Sustain=1, Tone=1, Volume=0,8;
действующее управление регуляторами ещё предстоит реализовать.

Полная Python-модель и схема ngspice служат отдельными эталонами.
Их ошибки и устойчивость нельзя автоматически переносить на составное ядро.
Последние проверки: [передача контекста](09%20Передача%20следующему%20чату.md).
