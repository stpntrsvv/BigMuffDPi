# Начало

Этот каталог — главный инженерный журнал проекта. Корневой `README.md` нужен
только для быстрого входа, а требования, решения, измерения и история работ
ведутся здесь.

## Текущее состояние

- Плата: NUCLEO-G474RE.
- Среда сборки: PlatformIO, основа STM32Cube.
- Доступ к периферии: напрямую через регистры CMSIS.
- Исходный язык: C11.
- Составное ядро всей педали: BDF2 1×, 48 кГц, полубуфер 32 отсчёта.
- АЦП/DMA/DSP/ЦАП реализованы; рабочая сборка использует живой ADC, но до монтажа
  внешнего смещения 1,65 В её аналоговый тракт не считается проверенным.
- Полный аккорд BDF2: 0/6000 опозданий, запас худшего блока около 1,35%.
- Регуляторы фиксированы: Sustain=1, Tone=1, Volume=0,8.

Состояние сверено 2026-09-06 по коду и сохранённым отчётам.
Актуальная точка входа — [передача контекста](09%20Передача%20следующему%20чату.md).
Журналы содержат историю прежних кандидатов; промежуточные выводы не следует
считать описанием текущей прошивки.

## Правила ведения

- Каждая крупная задача выполняется в отдельной ветке Git.
- Одно изменение должно выражать одну понятную инженерную мысль.
- Изменение устройства, поведения или методики сопровождается обновлением
  соответствующей страницы в `docs`.
- Непроверенные предположения помечаются как предположения.
- Измеренные величины сопровождаются условиями измерения.
- Исходные записи измерений и итоговые отчёты не смешиваются.
- Каждый численный опыт получает отдельный `report.md` в
  `simulation/experiments/<имя>/` и графики всех содержательных зависимостей.
- Машинные таблицы и журналы расчётов хранятся в `simulation/raw/`, а в Git
  входят воспроизводимые программы, отчёты и итоговые рисунки.
