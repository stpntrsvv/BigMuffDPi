# Устройство проекта

## Каталоги

- `src/` — прошивка, общее составное ядро и измерительные стенды.
- `include/` — интерфейсы и подготовленные коэффициенты моделей.
- `simulation/` — Python-модели, генераторы коэффициентов и программы опытов.
- `simulation/ngspice/` — эталонная схема и модели элементов.
- `simulation/experiments/` — отчёты, графики и звуковые результаты.
- `simulation/raw/` и каталоги `cache/` — исходные данные и кэши вне Git.
- `scripts/` — настройка FPU при сборке и вспомогательная работа с платой.
- `docs/` — требования, математика, решения и журнал; `docs/reference/` — справочные материалы.
- `.pio/`, `.venv/` — локальные сборки и окружение вне Git.

## Рабочий поток

```text
main → board_init / audio_engine_init / audio_io_init / audio_io_start
PA1 → OPAMP1 → ADC1 → DMA (32 отсчёта) → audio_engine_process
    → composed_pedal_process_sample → DMA → DAC1 → PA4
```

`board.c` настраивает плату, тактирование, время и светодиод. `audio_io.c`
управляет АЦП/ЦАП, таймером, DMA и телеметрией. `audio_engine.c` вызывает
общее ядро через `include/composed_pedal.h`.

Ядро находится в `src/composed_frontend_benchmark.c`: историческое имя
сохранилось, но файл используется измерительными сборками, рабочей прошивкой
и программой `simulation/composed_chord_host.c` на компьютере.

Архитектура: `Q4+Sustain+Q3 (3×3) → Q2 скалярный → Tone+Q1 (2×2)`.
Рабочий режим — BDF2 1×, 48 кГц, Sustain=1, Tone=1, Volume=0,8.
`audio_engine_set_controls()` пока только сохраняет значения и не меняет DSP.

## Сборки PlatformIO

| Окружение | Назначение |
|:---|:---|
| `composed_audio_runtime` | АЦП/DMA/DSP/ЦАП, BDF2, цифровой ноль на входе модели |
| `composed_bdf2_block_benchmark` | Полный аккорд блоками по 32, BDF2 |
| `composed_block_benchmark` | Такой же стенд с Эйлером |
| `composed_bdf2_q2_block_benchmark` | Эксперимент с полиномом, согласованным с BDF2 |
| `composed_bdf2_benchmark`, `composed_frontend_benchmark` | Короткие измерения составного ядра |
| `q3_*` | Исследования отдельного Q3 в `src/q3_benchmark.c` |
| `full_pedal_*`, `port_multirate_*`, `fmac_benchmark` | Стенды прежних архитектур и FMAC |
| `nucleo_g474re` | Базовый режим со сквозной обработкой без составной модели |

Режимы выбираются макросами в `platformio.ini`. Экспериментальные коррекции
границ выключены в рабочей сборке. STM32Cube предоставляет стартовые файлы
и описания устройства; звуковой тракт обращается к регистрам CMSIS.
`scripts/platformio_fpu.py` включает FPU при компиляции и линковке.

Результаты и ограничения: [передача контекста](09%20Передача%20следующему%20чату.md).
Ключевая техника ускорения нелинейных функций вынесена отдельно:
[метод малого приращения](10%20Метод%20малого%20приращения%20нелинейностей.md).
