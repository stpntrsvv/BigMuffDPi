# Устройство проекта

## Каталоги

- `include/` — открытые заголовочные файлы модулей.
- `src/` — исходный код для микроконтроллера.
- `docs/` — требования, решения, планы и журнал работ.
- `docs/reference/` — сохранённые справочные материалы.

## Модули

- `board` — начальная настройка платы, системный счётчик времени и светодиод.
- `audio_io` — будущая настройка АЦП, ЦАП, таймера и ПДП.
- `audio_engine` — граница будущей математической модели эффекта.
- `main` — запуск модулей и основной цикл.

## Предполагаемый поток данных

```text
АЦП -> входной буфер -> два каскада ограничения -> темброблок -> громкость -> ЦАП
```

Ввод-вывод и обработка разделены намеренно: это позволит проверять математику
на компьютере и менять способ передачи отсчётов без переписывания модели.

## Правило низкого уровня

Работа с периферией выполняется через определения регистров CMSIS. STM32Cube
используется для файлов запуска, таблицы прерываний и описаний устройства, но
не как обязательный слой HAL в звуковом тракте.
